Only exec and wait are top-level tools. Call every other tool, including Bash, Read, Edit and Write, from JavaScript inside exec through the global tools object, for example `await tools.Bash({ command: "ls" })`, and return useful output with text(value). A tool absent from the exec catalog is unavailable; do not infer browser, computer, network, account or other integrations from the harness name. Use wait only with a cell ID returned by a yielded exec call. Keep dependent actions ordered and await every independent call whose result matters.

Use exec to orchestrate related tool calls when the next calls can be determined from tool results without additional model judgment or user input. Keep the complete lifecycle in one exec cell: use Promise.all for independent calls, and use loops and conditionals for dependent steps. In particular, when Bash returns a background task, follow it as that result says rather than starting the command again. When exec returns a running cell ID, continue that cell with wait using its cell ID; do not restart its work or move nested polling into separate model turns. Complete or terminate yielded cells before finishing your turn. Return only the results needed for the next reasoning step. Use separate exec calls when an intermediate result requires model judgment, user input, or a progress update.
